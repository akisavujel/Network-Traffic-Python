# 🌐 Network Traffic Data Analysis

A data analysis project to identify patterns in network traffic and prepare data for intrusion detection using Python.

---

## 🔍 What's Inside

| Section | Description |
|---|---|
| Data Understanding | Dataset description and column explanations |
| Data Preparation | Loading, filtering, cleaning and transforming data |
| Data Analysis | Summary statistics and correlation analysis |
| Data Exploration | Charts, visualizations and hypothesis testing |
