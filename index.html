Network Traffic Data Analysis



The dataset contains various network flow features such as Destination Port, Flow Duration, Packet Counts, Packet Lengths, and other statistical metrics, along with a label indicating whether the traffic is BENIGN or an attack.

The objective of this analysis is to gain a deeper understanding of the network flow characteristics, identify relationships between features, and prepare the data for further machine learning model training for intrusion detection.
